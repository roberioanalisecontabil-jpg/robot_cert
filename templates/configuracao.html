Agente no Windows

Instale o Python no PC onde estão os .pfx e defina CERT_ROBOT_BASE_URL e CERT_ROBOT_API_KEY (se houver chave).

python agent\run_agent.py

O sistema interpreta os arquivos usando a palavra-chave "senha":

MeuNome certificado senha aMinhaSenha.pfx

Os alertas estão desligados. As configurações abaixo ficam guardadas.
