Quando uma consulta não funciona, a resposta traz um código HTTP e, em JSON, o campo detail com o motivo:

{
  "detail": "Chave de API só lê: use GET."
}

Erros e soluções

CódigoO que aconteceu?Como resolver?
401Falha na autenticação: a chave está errada, revogada ou expirada, ou a conta vinculada foi desativada ou perdeu o perfil de administrador.Confira se o cabeçalho é Authorization: Bearer seguido da chave completa, sem espaços a mais. Em Configuração › Chaves de API, confira se a chave está Ativa. Se não estiver, substitua a chave.
403Operação ou consulta não permitida: um método diferente de GET, ou uma rota que a chave não alcança.Use o método GET e confira se a consulta está na referência. As rotas bloqueadas estão em Restrições e limitações da API.
404Registro não encontrado.Confira o identificador informado no caminho (veja Identificadores).
422Parâmetro inválido: formato, valor ou limite fora do aceito.Confira o tipo, os valores aceitos e os limites na tabela de parâmetros da consulta. O campo detail indica qual parâmetro está errado.
429Muitas consultas em sequência.Aguarde alguns minutos e tente novamente. Em automações, espace as consultas.
503O portal não conseguiu estabelecer comunicação com o banco de dados.Tente novamente após alguns instantes. Se o erro persistir, procure a equipe de TI.

Perguntas frequentes

O Power BI pede usuário e senha. O que informar?

Escolha Anônimo. A chave já vai no cabeçalho Authorization da consulta, como mostra o guia do Power BI.

A consulta trouxe só 100 registros. Onde estão os outros?

As listas são entregues em páginas. Percorra as páginas ou use todas_filtradas=true, como em Como percorrer todas as páginas.

A resposta tem menos campos do que a tela. Por quê?

Por padrão, a API retorna apenas os campos essenciais. Para outros, use o parâmetro campos, descrito em Campos da resposta.

É possível alterar dados pela API?

Não. A API é exclusivamente de leitura. Alterações são feitas pelo portal.

A chave foi enviada por engano a outra pessoa. O que fazer?

Revogue a chave imediatamente e crie outra, seguindo Como substituir uma chave. Depois, confira na tabela de chaves se houve uso de um endereço IP desconhecido.
