Este artigo mostra como conectar cada ferramenta à API de leitura. Em todos os guias, a chave fica guardada fora do código e dos arquivos compartilhados.

Antes de começar: uma chave de API ativa e o endereço do portal. Nos exemplos, troque ENDERECO-DO-PORTAL pelo endereço da barra do navegador, sem o caminho.

{% call cuidado("A chave não vai no código") %}

Não escreva a chave diretamente em scripts, planilhas ou consultas que serão compartilhadas. Use a variável de ambiente, o parâmetro ou o cofre indicado em cada guia.

{% endcall %}

Postman

  1. Em Environments › New, crie a variável chave_certguard, marque o tipo secret e cole a chave em Current value. Crie também base com o endereço do portal (https://ENDERECO-DO-PORTAL). O Current value fica só no seu computador e não vai junto quando a coleção é exportada ou compartilhada.
  2. Selecione o ambiente no canto superior direito.
  3. Em uma requisição nova, escolha o método GET e escreva a URL, por exemplo {% raw %}{{base}}/api/certificados{% endraw %}.
  4. Na aba Authorization, escolha Bearer Token e, em Token, escreva {% raw %}{{chave_certguard}}{% endraw %}.
  5. Na aba Params, informe os filtros, por exemplo documento_tipo = cnpj e vence_em_dias = 60.
  6. Clique em Send.

Resultado esperado: status 200 OK e a resposta em JSON, no formato descrito em Como ler a resposta.

Exemplos com filtros

Cada linha da tabela corresponde a uma linha na aba Params (Key e Value). O Postman monta a URL automaticamente.

O primeiro exemplo, escrito na URL:

{% raw %}{{base}}/api/certificados?documento_tipo=cnpj&vence_em_dias=60&ordenar=vencimento{% endraw %}

Power BI

  1. Em Página Inicial › Transformar dados › Gerenciar Parâmetros › Novo Parâmetro, crie o parâmetro ChaveCertGuard, do tipo Texto, com a chave em Valor Atual.
  2. Em Obter dados › Consulta em branco, abra o Editor Avançado e cole a consulta abaixo.
  3. No aviso de credenciais, escolha Anônimo: a chave já vai no cabeçalho.
  4. Clique em Fechar e Aplicar.
let
    Fonte = Json.Document(Web.Contents(
        "https://ENDERECO-DO-PORTAL",
        [RelativePath = "api/certificados",
         Query = [todas_filtradas = "true"],
         Headers = [Authorization = "Bearer " & ChaveCertGuard]])),
    Certificados = Table.FromRecords(Fonte[itens])
in
    Certificados

Resultado esperado: uma tabela com uma linha por certificado e uma coluna por campo.

O parâmetro fica gravado dentro do arquivo .pbix. Compartilhe o arquivo somente com quem pode ter acesso à chave e, ao publicar no serviço do Power BI, prefira uma chave exclusiva para o relatório publicado.

Excel

O Excel usa o mesmo Power Query do Power BI.

  1. Em Dados › Obter Dados › De Outras Fontes › Consulta em Branco, abra o Power Query.
  2. Em Página Inicial › Gerenciar Parâmetros › Novo Parâmetro, crie o parâmetro ChaveCertGuard, do tipo Texto, com a chave em Valor Atual.
  3. Selecione a consulta em branco, abra o Editor Avançado e cole a mesma consulta do Power BI.
  4. No aviso de credenciais, escolha Anônimo.
  5. Clique em Fechar e Carregar.

Resultado esperado: uma planilha nova com a tabela de certificados. Para trazer os dados mais recentes, use Dados › Atualizar Tudo.

Assim como no Power BI, o parâmetro fica gravado dentro do arquivo .xlsx: antes de enviar a planilha a outra pessoa, apague o valor do parâmetro.

PowerShell

Guarde a chave uma vez em uma variável de ambiente da sua conta do Windows. Ela fica disponível nas próximas janelas do PowerShell.

[Environment]::SetEnvironmentVariable("CERTGUARD_CHAVE", (Read-Host "Chave de API" -MaskInput), "User")

Em uma janela nova, consulte:

$r = Invoke-RestMethod "https://ENDERECO-DO-PORTAL/api/certificados?filtro_status=prestes_vencer" `
  -Headers @{ Authorization = "Bearer $env:CERTGUARD_CHAVE" }
$r.itens | Format-Table nome, documento, vence_em, dias_para_vencer

Para percorrer todas as páginas, veja Como percorrer todas as páginas.

Python

Com a variável CERTGUARD_CHAVE criada como no guia do PowerShell (no Linux ou no macOS, com export CERTGUARD_CHAVE=… no perfil do usuário):

import os
import requests

BASE = "https://ENDERECO-DO-PORTAL"
CABECALHO = {"Authorization": "Bearer " + os.environ["CERTGUARD_CHAVE"]}

# Esta consulta devolve "linhas" e "tem_mais" (a de certificados usa "itens" e "paginacao").
linhas, pagina = [], 1
while True:
    r = requests.get(
        BASE + "/api/carteira/uso",
        params={"desde": "2026-11-01", "ate": "2026-11-30", "pagina": pagina, "por_pagina": 100},
        headers=CABECALHO,
        timeout=60,
    )
    r.raise_for_status()
    dados = r.json()
    linhas += dados["linhas"]
    if not dados["tem_mais"]:
        break
    pagina += 1

print(len(linhas), "usos")

cURL

No Linux ou no macOS, com a variável CERTGUARD_CHAVE definida:

curl -H "Authorization: Bearer $CERTGUARD_CHAVE" \
  "https://ENDERECO-DO-PORTAL/api/certificados/vencidos?data_inicio=2026-01-01"

No PowerShell do Windows, chame curl.exe e use $env:CERTGUARD_CHAVE:

curl.exe -H "Authorization: Bearer $env:CERTGUARD_CHAVE" "https://ENDERECO-DO-PORTAL/api/certificados/vencidos?data_inicio=2026-01-01"
