Este artigo mostra como fazer uma consulta de teste, conferir a resposta e percorrer todas as páginas de uma lista.

Antes de começar: uma chave de API ativa e o endereço do portal.

Como montar a consulta

Toda consulta é um GET com três partes:

ParteO que informarExemplo
Endereço do portalO mesmo da barra do navegador ao abrir o portal, sem o caminho. Nos exemplos da wiki, troque ENDERECO-DO-PORTAL por ele.https://portal.exemplo.com.br
ConsultaO caminho da consulta e, depois de ?, os filtros separados por &./api/certificados?documento_tipo=cnpj&vence_em_dias=60
Cabeçalho AuthorizationA palavra Bearer, um espaço e a chave.Bearer cg_ro_…

Consulta de teste

No Windows, abra o PowerShell e execute os comandos abaixo. O primeiro pede a chave sem exibi-la na tela nem gravá-la no histórico.

$chave = Read-Host "Chave de API" -MaskInput
$r = Invoke-RestMethod "https://ENDERECO-DO-PORTAL/api/certificados?por_pagina=5" `
  -Headers @{ Authorization = "Bearer $chave" }
$r.itens | Format-Table nome, documento, status, vence_em

Resultado esperado: uma tabela com até cinco certificados. Se aparecer um erro, veja Erros e soluções.

O -MaskInput existe a partir do PowerShell 7. No Windows PowerShell 5.1, use $chave = Read-Host "Chave de API".

Como ler a resposta

As respostas vêm em JSON. A única exceção é /api/perfil/foto, que devolve uma imagem JPEG. Uma resposta de /api/certificados com um certificado:

ObjetoO que contém
atualizado_emData e hora (UTC) da última leitura das pastas de certificados.
itensOs registros da página atual. Os campos de cada certificado estão em Campos da resposta.
vencidos_ocultosQuantos vencidos ficaram de fora por causa de ocultar_vencidos=true.
resumoTotais por situação, de todos os registros do filtro (não só da página).
paginacaoPágina atual, total de páginas, total de registros, registros por página e o máximo de todas_filtradas.

Como percorrer todas as páginas

As listas são entregues em páginas: /api/certificados traz 100 registros por página, se por_pagina não for informado. Para obter todos, repita a consulta aumentando pagina até chegar a paginacao.total_paginas.

$todos = @()
$pagina = 1
do {
  $r = Invoke-RestMethod "https://ENDERECO-DO-PORTAL/api/certificados?pagina=$pagina&por_pagina=500" `
    -Headers @{ Authorization = "Bearer $chave" }
  $todos += $r.itens
  $pagina++
} while ($pagina -le $r.paginacao.total_paginas)
"$($todos.Count) certificados"

Nas consultas que aceitam todas_filtradas=true, a resposta traz todos os registros do filtro em uma página, até o limite de export_max (5.000). Quando o limite é atingido, a resposta traz "lista_truncada": true.
