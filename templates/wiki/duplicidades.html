Esta página aponta certificados que aparecem mais de uma vez na pasta, para orientar a limpeza de cópias e arquivos antigos. Os casos são separados pelo grau de certeza. A análise considera os clientes da sua carteira.

Como ler a análise

  1. No menu lateral, clique em Duplicidades.
  2. Confira os três números do topo, cada um com um selo:
    • Mesmo certificado (Confirmado): cópias do mesmo arquivo.
    • Mesmo CPF/CNPJ (Provável): o documento se repete com outra assinatura. Pode ser uma renovação ou um certificado antigo esquecido na pasta.
    • Nomes parecidos (Revisar): o arquivo não abriu e a comparação foi feita apenas pelo nome. Pode haver engano.
    {{ print("dup-resumo", "Página Duplicidades com os três números Mesmo certificado, Mesmo CPF/CNPJ e Nomes parecidos", "Os três graus de certeza") }}
  3. Clique em um número para ir até a seção correspondente. {{ print("dup-confirmado", "Seção Mesmo certificado com os clientes e os arquivos repetidos") }}
  4. Em cada seção, veja o Cliente e os Arquivos envolvidos. {{ print("dup-revisar", "Seção Nomes parecidos com os grupos de arquivos a revisar") }}
{% call dica("Comece pelo Confirmado") %}

Confirmado é o caso seguro. Revisar exige conferência manual: clientes com nomes iguais podem aparecer ali.

{% endcall %}

Como copiar o local de um arquivo

  1. Na linha do arquivo, clique em Copiar caminho (administrador) ou Copiar nome (demais papéis). {{ print("dup-copiar", "Linha de um arquivo com o botão Copiar nome em destaque") }}
  2. Cole onde precisar: e-mail, chamado ou Explorador de Arquivos.

Como refazer a análise

  1. Clique em Atualizar. O botão muda para "Atualizando…" enquanto os arquivos são analisados. {{ print("dup-atualizando", "Botão Atualizar mostrando Atualizando enquanto a análise roda") }}

Dúvidas e erros comuns

{% call dica("O portal não apaga arquivos") %}

A limpeza da pasta é feita por quem administra o servidor de arquivos. Encaminhe a essa pessoa o que você encontrou.
