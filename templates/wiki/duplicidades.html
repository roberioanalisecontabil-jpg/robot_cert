Esta página aponta certificados que aparecem mais de uma vez na pasta, para limpar cópias e arquivos antigos. Os casos vêm separados pelo grau de certeza. A análise considera os clientes da sua carteira.

Ler a análise

  1. No menu lateral, clique em Duplicidades.
  2. No topo há três números, cada um com um selo:
    • Mesmo certificado (Confirmado): cópias do mesmo arquivo.
    • Mesmo CPF/CNPJ (Provável): o documento se repete com outra assinatura. Pode ser renovação ou certificado antigo esquecido na pasta.
    • Nomes parecidos (Revisar): o arquivo não abriu e a comparação foi só pelo nome. Pode ser engano.
    {{ print("dup-resumo", "Página Duplicidades com os três números Mesmo certificado, Mesmo CPF/CNPJ e Nomes parecidos", "Os três graus de certeza") }}
  3. Clique num número para pular até a seção correspondente. {{ print("dup-confirmado", "Seção Mesmo certificado com os clientes e os arquivos repetidos") }}
  4. Em cada seção, veja o Cliente e os Arquivos envolvidos. {{ print("dup-revisar", "Seção Nomes parecidos com os grupos de arquivos a revisar") }}

Copiar o local de um arquivo

  1. Na linha do arquivo, clique em Copiar caminho (administrador) ou Copiar nome (demais papéis). {{ print("dup-copiar", "Linha de um arquivo com o botão Copiar nome em destaque") }}
  2. Cole onde precisar: e-mail, chamado ou Explorador de Arquivos.

Refazer a análise

  1. Clique em Atualizar. O botão muda para "Atualizando…" enquanto os arquivos são analisados. {{ print("dup-atualizando", "Botão Atualizar mostrando Atualizando enquanto a análise roda") }}
