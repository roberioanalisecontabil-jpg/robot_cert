Configuração reúne os ajustes de funcionamento do portal: como as estações se identificam, quais pastas o agente do servidor lê, como saem os alertas por e-mail, os comandos para o agente e a ligação com o SIEG.

Só o administrador abre esta tela. Quem não é administrador e tenta abrir volta para o Início com o aviso Acesso restrito a administradores.

No alto da página, duas etiquetas mostram o estado do servidor: Banco de dados conectado (ou desconectado, ou não verificado) e Chave API obrigatória (ou aberta). A página tem cinco abas: Chave API, Pastas e agente, Alertas por e-mail, Fila de comandos e SIEG.

Aba Chave API

É só informativa: não tem campo nem botão de salvar. Ela explica que a chave das estações não passa pelo navegador. A chave é digitada no instalador do agente, que a guarda protegida no próprio computador.

{{ print("configuracao-chave", "Aba Chave API com as duas etiquetas de estado no topo e a explicação de como a chave entra numa estação", "A aba Chave API é só informativa.") }}

Trocar a chave de uma estação já instalada

É tarefa do técnico, feita no próprio computador da estação.

  1. Grave a chave num arquivo de texto.
  2. Abra o prompt de comando como administrador do Windows e rode o comando mostrado na aba, trocando o caminho pelo do seu arquivo.
  3. O agente guarda a chave e apaga o arquivo.

Aba Pastas e agente

Diz ao agente do servidor quais pastas olhar.

Mudar as pastas

  1. Preencha Origem (.pfx), onde estão os certificados, e Vencidos (destino), para onde vão os vencidos.
  2. ID do servidor identifica o agente. Normalmente fica default.
  3. No bloco Entrada de certificados, preencha Pasta de entrada, Pessoa jurídica (CNPJ) e Pessoa física (CPF). Deixar a pasta de entrada vazia desliga esse passo. Escreva os caminhos como o servidor os vê, não como aparecem no seu computador.
  4. Clique em Guardar e sincronizar.
  5. Confira em Leitura local efetiva os caminhos que valem. {{ print("configuracao-pastas", "Aba Pastas e agente com os campos de pastas preenchidos e a Leitura local efetiva carregada", "As pastas e a leitura efetiva.") }}
{% call cuidado("Caminho errado cega o agente") %}

Caminhos de pasta errados fazem o agente parar de ver certificados. Depois de Guardar e sincronizar, confira Leitura local efetiva e, se quiser, use Forçar leitura na Fila de comandos.

{% endcall %}

Gerar o arquivo de configuração do agente

  1. Confira o campo URL do portal no agent_config.json. Ele só vai para o arquivo baixado.
  2. Clique em Baixar agent_config.json e copie o arquivo para a pasta onde o agente está instalado. O arquivo não leva a chave.

O fim da aba lembra a regra do nome dos arquivos: a senha do certificado vem depois da palavra senha, por exemplo MeuNome certificado senha aMinhaSenha.pfx.

Aba Alertas por e-mail

Ligar ou desligar os alertas

  1. Use o interruptor Enviar alertas automaticamente. A etiqueta ao lado diz Ligado ou Desligado, e a frase embaixo diz o que está valendo.
  2. Clique em Salvar alterações, na barra do rodapé. Enquanto houver mudança pendente, a barra avisa que há alterações não salvas.

Escolher a forma de envio

  1. Em Enviar por, escolha SMTP (servidor de e-mail com usuário e senha) ou Microsoft 365 (aplicativo, pelo Graph). {{ print("configuracao-alertas-topo", "Interruptor Enviar alertas automaticamente, campo Enviar por e bloco Servidor de e-mail com a senha vazia e a etiqueta Senha guardada", "O interruptor geral e a forma de envio.") }}
  2. Para Microsoft 365, preencha ID do tenant (diretório), ID do aplicativo (cliente), Segredo do aplicativo, Segredo vence em, Caixa de envio (remetente) e Responder para. Esses dados vêm do cadastro do aplicativo feito pela TI no Microsoft 365. {{ print("configuracao-alertas-m365", "Forma de envio Microsoft 365 com o bloco Aplicativo no Microsoft 365 e o campo de segredo vazio", "Os campos do Microsoft 365.") }}
  3. Para SMTP, preencha Servidor, Porta, Segurança da conexão, Usuário, Senha e E-mail do remetente.
  4. Clique em Salvar alterações.

Os campos de senha e de segredo sempre aparecem vazios. Uma etiqueta ao lado diz Senha guardada ou Segredo guardado quando já existe um valor. Deixe o campo vazio para manter o atual; só digite para trocar.

{% call cuidado("Anote quando o segredo vence") %}

Preencha Segredo vence em com a data de validade do segredo do Microsoft 365: o sino do administrador avisa 30 dias antes. Sem a data, ninguém é avisado, e os alertas param no dia em que o segredo vencer.

{% endcall %}

Testar o envio

  1. Salve antes: o teste usa o que está salvo.
  2. Digite um e-mail em Enviar teste para e clique em Enviar teste.
  3. A resposta aparece logo abaixo: a confirmação de que o e-mail de teste foi enviado, ou o motivo da recusa.

Aviso de certificado novo

  1. Ligue Avisar quando chegar certificado novo para avisar os administradores e quem tem o cliente na carteira.
  2. Em Enviar, escolha A cada hora cheia (padrão) ou Imediatamente, a cada varredura com novos.
  3. Clique em Salvar alterações.

Para quem e quando sai o resumo

  1. Em Destinatários do resumo, escreva os e-mails separados por vírgula. Vazio envia para todos os administradores ativos. Um endereço fora da empresa faz aparecer o aviso Endereço fora da empresa.
  2. Em Prazos de aviso, escreva os dias antes do vencimento, separados por vírgula. A linha embaixo do campo mostra os prazos em uso. O aviso de que o certificado venceu é sempre enviado.
  3. Em Verificar a cada, escolha 20 horas (padrão), 12 horas, 24 horas ou 7 dias. É o intervalo entre verificações, não um horário fixo. {{ print("configuracao-alertas-quem-quando", "Blocos Certificado novo e Para quem, e quando, com os destinatários, os prazos de aviso, o intervalo e o botão Disparar agora", "Quem recebe o resumo e com que frequência.") }}
  4. Clique em Salvar alterações.

Mandar o resumo agora

  1. Clique em Disparar agora.
  2. A janela Disparar o resumo agora diz para quem vai. {{ print("configuracao-alertas-disparo", "Janela Disparar o resumo agora com os destinatários, antes de confirmar", "A confirmação antes de disparar o resumo.") }}
  3. Clique em Enviar agora só se quiser mesmo enviar. Para desistir, clique em Cancelar.
{% call cuidado("Disparar agora manda e-mails de verdade") %}

Disparar agora é o mesmo envio do horário, com e-mails reais para os destinatários. Para testar, use Enviar teste com o seu próprio e-mail.

{% endcall %}

Mudar o texto do e-mail

  1. Em Texto do e-mail, clique em Editar texto….
  2. Ajuste Assunto, Título, Abertura e Recado final. Os botões em Variáveis disponíveis inserem dados automáticos no ponto onde está o cursor. A prévia, à direita, mostra o resultado. {{ print("configuracao-alertas-texto", "Janela Texto do e-mail de alerta com os campos Assunto, Título, Abertura e Recado final e a prévia à direita", "O texto do e-mail e a prévia.") }}
  3. Clique em Salvar. Restaurar padrão limpa os campos, mas ainda é preciso salvar.

Aba Fila de comandos

Manda ordens para o agente do servidor de certificados.

  1. Confira o Servidor alvo. Normalmente é default.
  2. Clique em Forçar leitura para o agente reler as pastas agora, sem esperar o intervalo normal. Ping só testa se o agente responde.
  3. A tabela Pendentes mostra o que o agente ainda não buscou. Clique em Atualizar para recarregar. {{ print("configuracao-comandos", "Aba Fila de comandos com o campo Servidor alvo, os botões Forçar leitura e Ping e a tabela Pendentes", "A fila de comandos do agente.") }}
{% call dica("Comando parado há mais de um dia") %}

Um comando pendente há mais de um dia costuma indicar agente parado ou nome de servidor errado em Servidor alvo.

{% endcall %}

Aba SIEG

Liga o portal à conta do SIEG. Quando alguém liga o SIEG nos detalhes de um certificado, no Início, o portal envia o certificado ao SIEG. As tentativas ficam no Instalador, aba SIEG.

Configurar as credenciais

  1. No SIEG, abra Minha conta e depois Integração API SIEG.
  2. Copie Client ID, Secret Key e API Key para os campos de mesmo nome. A API Key é diferente da Secret Key. Os campos secretos aparecem vazios; a etiqueta Guardada indica que já existe valor, e Não informada, que ainda não.
  3. Em Cadastro no SIEG, ajuste UF do certificado (código IBGE) (27 é Alagoas), Dias retroativos e Consulta de NFS-e, e marque as Consultas desejadas. Isso vale para todo certificado enviado. {{ print("configuracao-sieg", "Aba SIEG com as credenciais, os campos secretos vazios com suas etiquetas e a grade de Consultas", "As credenciais e o cadastro no SIEG.") }}
  4. Clique em Salvar.
  5. Clique em Testar conexão para conferir.

Acertar o que já está no SIEG

  1. Clique em Sincronizar com o SIEG. Os certificados que já estão na conta do SIEG ficam marcados como No SIEG. Nada é enviado.
{% call cuidado("Segredo não vai para print, e-mail ou chamado") %}

Nunca deixe uma senha ou um segredo à vista num print, num e-mail ou num chamado. Os campos de senha voltam vazios de propósito: deixe vazio para manter o valor atual.

{% endcall %}
